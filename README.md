# tylon-stress-test

This repository is a Stress Test for Tylon.

## Simple API (NestJS)

### Install

```bash
npm install
```

### Build

```bash
npm run build
```

### Dev (watch / hot reload)

```bash
npm run dev
```

### Test

```bash
npm run test
```

### E2E

```bash
npm run test:e2e
```

JWT secret for local development and tests:

```bash
JWT_SECRET=tylon-stress-test-dev-secret
```
